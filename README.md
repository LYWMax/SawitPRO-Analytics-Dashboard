# SawitPRO Data Discovery & Visualisation Dashboard

Individual assignment for the **Data Discovery & Visualisation (DDV)** module at Ngee Ann Polytechnic, Diploma in Data Science. This project explores operational and user activity data from **SawitPRO**, an Agritech startup connecting stakeholders in the palm oil supply chain across Indonesia.

## Project Overview

The goal of this project was to design and build an interactive Tableau dashboard to explore two datasets provided by SawitPRO, uncover meaningful insights, and present findings through data storytelling.

**Datasets explored:**
- **Order Dataset** — product sales by category, order cancellations, and delivery time analysis
- **User Activity Dataset** — user activity patterns by location and time (UTC+7), with a focus on identifying peak usage trends

## Process

1. **Data Preparation** — Cleaned and prepared both datasets for analysis, including handling missing values and verifying data consistency.
2. **Exploratory Data Analysis** — Performed univariate and multivariate analysis to identify trends in sales, cancellations, delivery times, and user activity patterns.
3. **Visualisation Design** — Built a library of visualisations in Tableau, each tied to a specific exploratory question.
4. **Dashboard Development** — Combined the most relevant visualisations into a cohesive dashboard for data storytelling.
5. **Presentation** — Delivered a recorded presentation walking through key insights for the target audience.
